# ADR-0015：项目不维护自动化测试用例

- 状态：Accepted
- 日期：2026-08-04
- 决策者：项目所有者
- 关联模块：全部模块、构建系统和开发流程

## 背景

仓库此前维护单元、契约、集成、进程、视觉冒烟和管理员 E2E 测试，并通过 CTest 与构建脚本执行。
项目所有者决定删除全部 Aegra 自有测试用例，后续开发不再编写或维护测试用例。

## 决策

1. 仓库不保留或新增单元、契约、集成、回归、冒烟、E2E、fuzz、属性测试或 CTest 用例。
2. 禁止新增测试源码、fixture、golden data、测试专用脚本、测试可执行 Target 和 CMake 测试注册。
3. 删除现有 `tests/`、测试运行产物、管理员 E2E 脚本和对应测试说明。
4. 变更验证改为受影响生产 Target 构建、静态/架构/源码规模检查，以及按风险执行的人工运行或 UI 验证。
5. 交付说明必须列出实际构建和人工验证范围；不得把“未编写测试”报告为遗漏项。
6. `third_party` 中供应商源码自带的测试资产不属于 Aegra 测试套件，可以随上游源码保留，但不得注册到
   Aegra 构建、CTest 或项目验证流程。
7. 产品中的 Repository connection `Test` 命令属于运行时业务能力，不受本决策影响。

本 ADR 取代此前 ADR、格式规范、模块文档和迁移计划中要求新增、维护或运行自动化测试的条目。旧文档中的
测试描述仅保留为历史记录，不再构成实施或完成门禁。

## 备选方案

- 保留现有测试并停止新增：拒绝，项目所有者要求删除全部测试用例。
- 仅从默认构建移除测试：拒绝，仍会留下需要维护的测试资产。
- 保留少量协议或安全测试：拒绝，本决策适用于所有 Aegra 自有测试类型。

## 影响

- 构建图和日常构建更简单，不再生成或运行测试 Target。
- 回归、边界错误和平台差异无法通过自动化测试提前发现，工程风险转移到代码审查、静态检查和人工验证。
- 高风险的格式、加密、恢复、权限和持久化变更需要更明确的人工验证范围与结果记录。
- 未来如需恢复任何项目测试，必须提交新的 ADR 取代本决策。

## 验证

- 项目自有源码树不存在 `tests/` 或测试专用脚本。
- 顶层 CMake、Preset 和构建脚本不包含 CTest 或测试 Target 注册。
- Debug/Release 生产 Target 可以构建，源码规模和其它现存静态检查可以独立运行。
